# NekoBox UI

NekoBox Android UI 构建工具集。默认基于官方 r98 源码，保留官方配置卡片、节点撤销、分组撤销和批量操作撤销逻辑。

## 协议开关

- 普通 VLESS：标准 VLESS 握手。
- VLESS UUID 末尾 `#x365`：内部切换 x365 魔改握手，界面和导出类型仍为 VLESS。
- ViewTurbo：SS 密码末尾 `#vt` 才启用。
- Fastup：Trojan 密码末尾 `#fastup` 且存在 mpw 才启用。

普通节点不带后缀时，保持原生协议行为。

## UI 行为

- 配置页节点卡片沿用官方源码布局。
- 搜索后删除仍进入统一撤销流程。
- 清理不可用配置保留撤销提示。
- 清空、滑动删除、分组删除均保留撤销。
- 链式代理手动选择配置时，选择列表与右侧按钮对齐。
- 出站 IP 查询支持快速 IP 展示和后续国家、类型、组织、ASN 增量补全。
- 剪贴板导入订阅后自动选中新建订阅分组。

## 构建

通过 GitHub Actions 手动构建，构建时指定上游源码提交和协议模块提交。仓库不记录具体发布版本号、构建编号或历史 APK 信息。
