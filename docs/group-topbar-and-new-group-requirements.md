# 配置页分组名称栏与新建分组流程改动需求

来源：用户附加需求文档（2026-11-07）。

## 需求一：新建分组不得重复压入分组设置

从配置界面点击“新建分组”后，页面栈只能有一层 `GroupSettingsActivity`。保存、取消、系统返回键或手势都必须一步返回配置界面，不得出现两层分组设置页面。中间命名或确认流程不得重复启动设置路由。

验收：

- [ ] 新建分组流程中分组设置只出现一次。
- [ ] 点击保存后一步回到配置界面。
- [ ] 取消、返回键和返回手势同样一步回到配置界面。

## 需求二：顶栏分组名称位置稳定

- 删除非选定分组后，顶栏保持原可视位置，其余名称只做必要补位，不回到首项。
- 删除选定分组时，默认选中前一个分组；删除第一项则选中后一个，顶栏平滑跟随新选定项，不出现未选定闪烁。
- 新建分组追加到列表末尾并默认选中，顶栏平滑滚动到末尾并显示新分组。
- 任何删除、新建操作不得使顶栏瞬间跳到首个分组。

## 需求三：删除分组名称动画

删除非选定分组：被删项在 250–300ms 内缩小并淡出，左右项目同步合拢；贴近一端时保持贴边侧不动，由另一侧补位。

删除选定分组：在上述动画中同步转移高亮背景和选定状态，选定优先转移到前一个项目；首项被删时转移到后一个项目。

撤销删除：动画完全反向，被删项在原位置淡入并放大，其他项目退回原路径，选定项和高亮同步恢复。

建议曲线为 easeOutCubic，连续操作必须可中断或合并，避免动画叠加错乱。

## 范围

仅涉及配置页顶栏导航、选定状态、删除动画和“新建分组”路由栈；不改变分组内节点列表、订阅更新和测速业务。

## 验收清单

- [ ] 删除中间、左端附近、右端附近项目均无瞬移和空隙。
- [ ] 删除选定项时选定转移规则正确，高亮随动画移动。
- [ ] 撤销可逆。
- [ ] 新建后顶栏显示末尾新分组且处于选定态。
- [ ] 页面栈不重复压入分组设置。
