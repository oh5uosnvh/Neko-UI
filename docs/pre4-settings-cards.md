# pre4 设置区域卡片与标题边缘优化

基线：`f6933ff3e522f1b7d017334c97f6c4e47f7c0d5b`，GitHub 构建 #287 / 发布 `1.4.2-mg-pre4`。

## 范围

- 导航入口改为三条等长的 ☰ vector；紧凑菜单使用节点卡片相同的描边资源。
- 保留按需访问过的 Fragment，不在冷启动后连续 inflation 六个未访问页面；弹窗完整退出后，等待目标页面内容、首轮列表绑定及连续绘制帧准备好再开始同样 260ms 的双页平移。
- 设置页嵌套 PreferenceFragment 归自己的 childFragmentManager 管理，并在首帧前完成创建；恢复已有子页，不重复构造。
- 原 PreferenceCategory 分界改为整组描边圆角卡片，包括无标题的前导区域；标题在卡片内左上角。原始 Preference 对象、键、监听器、依赖和 payload 开关重绑保留。
- 卡片颜色读 `colorLayerHigh`；页面与工具栏颜色读 `colorLayerLow`；不更改原主题主色、夜间调色板、卡片半径/描边资源。取消顶部阴影、分割线与滚动抬升。
- 设置、协议/路由/分组编辑、WebDAV、关于、文本编辑、应用选择采用标题文字实际 ink bottom 作为消失基线，不以 toolbar.bottom 或 TextView 的字体留白作为基线。动态列表、系统边距、底部键盘和返回重挂载保留初始间距。
- 仅处理标题字形底部至工具栏底部的狭窄区域，静止首卡仍清晰。API31+ 硬件使用局部 RenderNode 模糊，旧版/软件画布使用同位置渐隐。横向平移时停用模糊录制，不对整页做 bitmap/RenderEffect。
- 应用筛选卡（包括搜索和系统应用开关）作为同一 RecyclerView 首行滚动；快滚索引和批量开关位置排除头部。加载期间筛选仍可操作。

## 验证边界

新增/保留真实 AndroidX 列表交互、分类隐藏恢复、动态增删、switch payload、首帧门禁、返回/取消、主题、卡片长区域与标题边缘像素测试。云端原工作流仍执行所有 `group.*` 测试及双架构同签名 Release 构建；没有跳过既有失败门禁。

手机 Alpine/aarch64 不支持 Robolectric 原生绘图库，因此本机只验证 API28 非原生用例；API33/35 原生像素测试在 Ubuntu/JDK21 CI 执行。生成的截图来自实际 Android 布局与控件的 Robolectric 渲染，不是真机截图，也不能替代用户设备的帧率验收。

内核、协议模块固定版本、数据库迁移、包名、VPN 服务以及原签名流程不变。候选构建与旧 pre4 发布分开，不覆写既有 APK/标签。
